# Notch logo

1:1 logo of Notch. Colors: purple `#413A68`, yellow `#FAD84A`, teal `#12A8B5`, dark `#2A2547`.

| File | Use |
|---|---|
| `notch-logo.svg` | Master file, vector, with purple background |
| `notch-logo-transparent.svg` | Same logo without background |
| `notch-logo-1024.png`, `-512`, `-256`, `-128`, `-64`, `-32` | Raster sizes with background |
| `notch-logo-transparent-1024.png`, `-512` | Raster without background |
| `notch-logo.webp`, `notch-logo.jpg` | 1024 px, for web and for forms that ask for JPG |
| `favicon.ico` | 16, 32, 48 and 64 px |

Direct link for forms and embeds: `https://raw.githubusercontent.com/josecadenax/notch/main/docs/assets/logo/notch-logo-1024.png`
